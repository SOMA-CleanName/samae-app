이 문서는 **캡처 색인**이다. 화면이 바뀌면 다시 찍어야 하므로,
어떤 상태에서 찍은 것인지를 함께 적어둔다.

---

## 캡처 방식 — 왜 통짜 스크린샷이 아닌가

처음에는 화면 전체를 다크 모드로 찍었는데 읽히지 않았다. 이유가 넷이었다.
문서 안에서 다크 모드는 대비가 떨어지고, Next.js 개발 아이콘이 좌상단에 겹치고,
한 화면에 카드가 여러 장 섞여 어디를 보라는 건지 알 수 없고, 캡처 자체에 설명이 없었다.

그래서 **화면에서 그 요소만 잘라내 설명을 붙인 '그림'** 으로 바꿨다.
목업이 아니라 실제 DOM 을 복제한 것이고, 스크립트로 재현된다.

```
┌──────────────────────────────────────┐
│ (4) 고객이 동의해야 연락처가 넘어갑니다  │  ← 번호 + 제목 + 한 줄 설명
│     받기 전에 환불 조건이 …             │
│  ┌────────────────────────────────┐  │
│  │  실제 화면에서 복제한 그 카드     │  │  ← 흰 카드 + 그림자
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

### 다시 찍는 법

```bash
node scripts/reset-roleplay.cjs Hyun     # 필요하면 방 초기화
npm run dev
cp scripts/capture-fig.js public/_fig.js  # 헬퍼를 dev 서버에 노출 (끝나면 지운다)
```

브라우저(Chrome DevTools MCP)에서:

1. `emulate` — `viewport = 390x844x3,mobile,touch`, `colorScheme = light`
   창 크기(`resize_page`)로는 Chrome 최소 폭(500px)에 막혀 모바일이 되지 않는다.
2. 페이지에 `/_fig.js` 를 `<script>` 로 주입 → `window.__fig` 가 생긴다.
3. `__fig(요소, 번호, 제목, 설명, 옵션)` → 그림을 만들고 **필요한 높이(px)** 를 돌려준다.
4. 그 높이로 다시 `emulate` (`390x<높이>x3`) 하고 `take_screenshot`.

`__fig` 는 개발 아이콘(`nextjs-portal`)과 페이지의 고정 요소(뒤로가기 버튼·탭바)를
자동으로 숨긴다. 옵션은 `w`(상자 폭) · `maxH`(잘라낼 높이) · `boxCss` · `bg` ·
`panels`(장면을 카드로 나누고 사이에 화살표) · `maxHs`(panels 각각의 높이).

같은 파일의 다른 함수:

| 함수 | 하는 일 |
|---|---|
| `__anon()` | 실명을 지우고(Hyun·임세현 → 사매작가 1, 베라치노 → 사매작가 2) 프로필 이미지를 사매 로고로 바꾼다 |
| `__logoPhoto(sel)` | 실사진을 사매 로고 이미지로 바꾼다 (사진 상세처럼 남의 사진을 실을 수 없는 자리) |
| `__mark(el)` | 그 요소를 빨간 링으로 강조한다 (`__fig` 전에 호출) |

**문서에 실명·실사진을 넣지 않는다.** 캡처 직전에 `__anon()` 을 부르는 걸 잊지 말 것.
원본 DB 는 건드리지 않으므로 새로고침하면 원래대로 돌아온다.

지나간 상태(연락처 전달 전 등)는 `node scripts/capture-state.cjs <preset>` 으로 되돌린다.

## 뺀 것

문의 폼·로그인 게이트·자주 묻는 질문 칩·입금 확인 안내·고객 문의 탭·환불 견적·
스튜디오 홈·예약서 작성기 전체는 작가님이 알아야 할 흐름과 거리가 있어 **의도적으로 뺐다.**
필요하면 같은 방식으로 다시 찍는다.

## 못 찍은 것

- **사진 설명 오버레이**(작가의 글) — 테스트 사진에 글이 없어 빈 화면이 나온다.
- **작가 안내 이미지** — 테스트 계정에 등록된 이미지가 개발 화면 스크린샷이라 못 쓴다.
  실계정으로 한 번 더 찍을 것.

## 남은 실명

`fig-1-5-deposit-dialog` 의 **예금주 이름**은 사매 플랫폼 계좌라 그대로 뒀다.
고객이 결제할 때 실제로 보는 값이다. 가려야 하면 `__anon` 의 `NAMES` 에 추가한다.

## 주의

다른 탭이 그 채팅방을 열어두면 `markRead` 가 계속 돌아 안읽음 배지가 0 으로 지워진다.
배지를 찍을 때는 그 방을 연 탭을 모두 닫는다.
