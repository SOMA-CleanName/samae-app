## 다시 찍을 때

```bash
node scripts/reset-roleplay.cjs           # 김재즈 방 초기화
npm run dev
```

캡처는 Chrome DevTools MCP 로 찍었다. 상태별 화면은 DB 를 직접 만져 단계를 만든 뒤 찍는다
(예약 제안 → 수락 → 입금 → 사매 확인 → 연락처 전달 순서로 진행하면 한 번에 이어서 찍힌다).

**주의**: 다른 탭이 그 채팅방을 열어두면 안읽음이 계속 0 으로 지워져 배지가 안 찍힌다.
