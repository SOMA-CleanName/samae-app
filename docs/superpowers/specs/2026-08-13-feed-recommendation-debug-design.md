# 로컬 추천 승격 디버그 설계

## 목적

`?feedDebug=1`에서 같은 스타일 사진을 반복 클릭할 때 노출 낮춤 추천 사진이 실제로 단계적으로 승격되는지 화면에서 검증한다.

## 진단 메타데이터

- 개발 환경에서 개인화 추천 결과에만 `demoted`, `naturalRank`, 최종 `insertedRank`, `promotionStage`, `styleConsistency`, `anchorCount`를 붙인다.
- 운영 빌드와 일반 데이터 응답에는 진단 메타데이터를 붙이지 않는다.
- 메타데이터는 추천 순위 관찰용이며 실제 정렬 계산에는 사용하지 않는다.

## 화면

- `?feedDebug=1` 상단 패널에 클릭 수, 승격 단계, 스타일 일관성, 이번 추천 장수를 표시한다.
- 추천 카드에 `일반 추천` 또는 `노출 낮춤` 배지와 `자연 순위 → 현재 위치`를 표시한다.
- 추천 메타데이터가 없는 기본 사진에는 배지를 표시하지 않는다.
- 최근 추천된 노출 낮춤 사진 ID와 위치 변화는 상단 패널의 접이식 목록에서 확인한다.

## 초기화

- `추천 이력 초기화` 버튼은 공유 클릭 이력과 디버그 피드 세션 캐시를 삭제한다.
- 초기화 뒤 홈을 새로고침해 클릭 0장, 승격 1단계 상태에서 다시 시작한다.

## 검증

- 순수 메타데이터 생성 테스트에서 최종 삽입 위치와 노출 낮춤 상태가 정확한지 확인한다.
- 관련 테스트, 타입 검사, 프로덕션 빌드를 실행한다.
