## 2. 시나리오 — 상담 트랙 (권장 1회차)

### ① 손님 — 봇과 상담
1. 손님 창에서 상담 URL 진입 → 김재즈 채팅방으로 자동 이동
2. **확인**: 봇 아바타 + `사매 안내봇` 이름이 헤더의 작가(김재즈)와 시각적으로 구분되는가
3. **확인**: 첫 인사가 “작가님이 확인하시기 전까지는 제가 대신 안내해드릴게요” 톤인가
4. 칩을 눌러 `가격이 어떻게 되나요?` → KB 그대로 답하는가
5. 직접 입력: `안녕하세요` → **되묻지 않는가** (봇은 답만 한다)
6. KB에 없는 질문: `주차장이 있나요?` → 지어내지 않고 작가에게 넘기는가

### ② 작가 — 미답변 질문 확인 후 개입
7. 작가 창 `/studio/chat` → 그 방 열기
8. **확인**: 상단에 `봇이 답하지 못한 질문 n개 — 작가님 답변이 필요해요`
9. 작가가 아무 말이나 보낸다 (예: `안녕하세요! 주차 가능합니다.`)
10. **확인 (손님 창)**: 봇이 먼저 `작가님이 대화에 들어왔어요…` 를 **작가 메시지보다 위에** 남기는가
11. **확인**: 이후 손님이 뭘 보내도 봇이 다시 끼어들지 않는가 (영구 정지)

### ③ 예약 제안 — 촬영비 + 출장비 분리
12. 작가 창 헤더의 달력 아이콘 → 예약 작성기
13. 날짜·시간 선택, **촬영비 100,000 / 출장비 20,000** 입력 → 합계 ₩120,000 이 실시간으로 뜨는가
14. 제안 전송
15. **확인 (손님 창)**: 카드에 `촬영비 ₩100,000  출장비 ₩20,000` 이 분리 표기되고 합계가 ₩120,000

### ④ 결제 — 사매 계좌 에스크로
16. 손님이 `수락`
17. **확인**: 사매 계좌(카카오뱅크 3333-37-7012994)가 안내되는가. **작가 개인 계좌가 어디에도 안 보여야 한다**
18. 손님이 `입금 완료` 누름 (실제 이체는 하지 않아도 된다)
19. **확인 (작가 창)**: “사매가 확인 중이에요” 로만 보이고, 작가가 직접 입금확인하는 버튼은 **없어야 한다**

### ⑤ 운영 — 입금 확인 → 정산
20. 같은 시크릿 창에서 `/admin/transactions`
21. `💰 입금 확인 대기` 큐에 뜨는가 → `[입금 확인]`
22. **확인**: 상태가 `paid` 로 바뀌고 수수료 6,000원이 잡히는가
23. `📤 정산 대기` 큐 → 송금액이 **120,000 − 6,000 = 114,000** 인가
24. `[정산 완료]`

### ⑥ 작가 — 수령 확인
25. 작가 창 채팅방 → `정산 받았어요` / `아직 못 받았어요` 버튼
26. `아직 못 받았어요` 를 누르면 `/admin/transactions` 의 `⚠️ 정산 미수령 확인 요청` 큐에 뜨는가

## 3. 시나리오 — 예약 트랙 (2회차)

`node scripts/reset-roleplay.cjs` 로 초기화하고, 손님 2번 계정으로:

1. `/inquiry?photographerId=99d988d6-...` 진입
2. **확인**: 질문 4개만 묻고 **연락처 단계가 없는가**
3. 마지막 확인 화면에 “연락처는 작가에게 공개되지 않아요”
4. `작가님께 문의 보내기` → 채팅방으로 이동하며 **문의 내용 정리 카드**가 방에 꽂히는가
5. **확인 (작가 창)**: 방 상단 체크리스트, 요약 카드의 `이 내용으로 예약 제안`
6. 이후 ③~⑥ 동일

## 4. 곁다리로 같이 볼 것

- **검열**: 아무 쪽에서 `010-1234-5678`, `카톡 abc123`, `국민은행 123-456-789012` 전송 → 차단되고 `/admin/chats` 에 기록되는가
- **봇 킬스위치**: `/admin/bot-kb` → 전역 정책 → `봇 응답 사용` 끄기 → 손님이 KB에 있는 질문을 해도 봇이 답하지 않고 넘기는가 (**테스트 후 다시 켤 것**)
- **고정 메시지**: 같은 화면에서 봇 이름·인사말을 바꾸면 채팅방에 바로 반영되는가
- **KB 빈틈**: 손님이 KB에 없는 걸 물을 때마다 `bot_open_questions` 에 쌓인다 → 작가 화면 상단 배너

## 5. 테스트 끝난 뒤

1. `node scripts/reset-roleplay.cjs` — 대화·예약 정리
2. 사진을 공개했다면 `visibility='draft', price_krw=null` 로 되돌리기
3. 김재즈 임시 비밀번호가 불편하면 알려줄 것 (되돌릴 수 있다)
4. 김재즈 KB 7장은 **테스트용 가짜 내용**이다 (`운영 메모`에 표시해둠) — 실제 정책과 다르니 실사용 전 정리
