## 1. 지금 사용자가 겪는 것

```
지금      카카오 로그인 → [번호 입력] → [인증번호 6자리] → 가입완료
승인 후   카카오 로그인 →     동의 ✓                    → 가입완료
```

"간편가입"을 눌렀는데 타이핑을 두 번 더 시키고 있습니다. 가입 퍼널에서 제일 두꺼운 벽이 여기예요.

## 2. 해야 할 일 — 순서대로

### ① 카카오 비즈니스 채널 → 비즈니스 인증

`business.kakao.com` → 사매 채널 → **비즈니스 채널 전환 / 비즈니스 인증**

사업자등록번호로 하는 인증입니다. 아래 §3 정보를 그대로 넣으면 됩니다. **②③④가 전부 이것에 걸려 있으니 이게 첫 번째입니다.**

### ② 개발자 콘솔 → 동의항목에 전화번호 추가

`developers.kakao.com` → 내 애플리케이션 → 사매 앱 → **카카오 로그인 → 동의항목**

`phone_number`(전화번호)를 찾아 **필수 동의 또는 선택 동의로 설정 + 권한 신청**.

이건 그냥 켜지는 게 아니라 **카카오 검수를 받습니다.** 신청서에 "왜 필요한가"를 적어야 하는데, 문안은 §4에 복붙용으로 써뒀습니다.

### ③ 카카오싱크 제휴 신청

같은 콘솔에서 **카카오싱크** 신청. 요구하는 것 —

- 카카오톡 채널 연결 (①에서 인증된 채널)
- **서비스 이용약관 URL** ← ⚠️ §6 확인
- **개인정보 처리방침 URL** ← ⚠️ §6 확인
- 앱 아이콘 · 앱 이름 · 서비스 설명

### ④ 알림톡 발신프로필 등록

`solapi.com`(이미 SMS로 연동돼 있는 대행사) → **카카오 알림톡 → 발신프로필 등록**

①에서 인증된 채널을 연결합니다. 그다음 **템플릿 심사**가 있는데, 문안은 정훈이가 따로 정리해서 드립니다. 형이 하실 건 발신프로필까지예요.

## 4. 전화번호 동의항목 신청 사유 (복붙용)

> 사매는 사진작가와 이용자를 연결하는 촬영 중개 서비스입니다.
>
> 이용자가 작가에게 문의를 남기면 작가와 채팅으로 상담이 이어지는데, 본 서비스는 모바일 웹으로 제공되어 브라우저 푸시 알림의 도달이 보장되지 않습니다. 그 결과 작가가 답장을 보내도 이용자가 이를 인지하지 못해 상담이 중단되는 사례가 발생하고 있습니다.
>
> 수집한 전화번호는 다음 세 가지 거래 알림의 발송에만 사용합니다.
> ① 작가의 답장 도착 ② 예약 확정 및 결제 안내 ③ 정산·환불 처리 결과
>
> 광고성 정보 발송에는 사용하지 않으며, 발송 대상은 해당 거래의 당사자로 한정됩니다. 동일 대화당 4시간 쿨다운을 적용해 중복 발송을 억제하는 로직이 이미 구현되어 있습니다.
>
> 현재는 이용자가 가입 직후 전화번호를 직접 입력하고 SMS 인증번호를 확인하는 절차를 거치고 있으며, 카카오싱크 도입 시 이 절차를 대체해 가입 과정을 단축하고자 합니다.

마지막 문단이 핵심입니다 — **새로 뭘 하겠다는 게 아니라 이미 받고 있는 걸 간편하게 바꾸는 것**이라는 게 검수에 유리합니다.

## 5. ⚠️ 건드리면 안 되는 것

**Redirect URI 를 바꾸지 마세요.** 카카오 로그인이 Supabase를 거쳐서 오기 때문에, 여기가 바뀌면 **로그인 전체가 즉시 죽습니다.**

```
https://gdcqqregcreovsrthnvo.supabase.co/auth/v1/callback
```

동의항목 추가는 Redirect URI와 무관하니 그냥 두시면 됩니다.

그리고 **동의항목을 승인 전에 "사용함"으로 켜두지 마세요.** 미승인 동의항목을 요청하면 카카오가 로그인 자체를 거절합니다(`KOE205`). 앱 코드는 환경변수로 막아뒀지만, 콘솔 쪽에서 먼저 켜지면 곤란합니다. **승인 통보를 받은 뒤에 정훈이한테 알려주시면 그때 같이 켭니다.**

## 6. 🔴 검수에서 걸릴 것 같은 것 — 정훈이가 처리

형이 하실 일은 아니지만, 신청 전에 정리돼야 해서 같이 적습니다.

### (1) 이용약관이 껍데기입니다

`https://samae.ai/terms` 는 지금 **목차만 있고 본문이 없습니다.** `noindex` 도 걸려 있어요. 법무 검토 전에 조항을 지어 쓰면 그게 곧 회사의 약속이 되기 때문에 일부러 비워둔 겁니다.

그런데 **카카오싱크 검수는 이용약관 URL을 필수로 봅니다.** 반려 사유가 될 수 있습니다.

### (2) 개인정보 처리방침이 실제 운영과 어긋납니다

`/privacy` 3조:

> 이용자가 선택한 사진작가에게 **연락처** 및 상담 정보를 제공할 수 있습니다

그런데 `/trust` 에는 이렇게 적혀 있습니다:

> 작가는 고객의 전화번호를 볼 수 없습니다

**리드 모델 시절 문안이 남은 겁니다.** 지금은 연락처가 작가에게 안 가요. 검수관이 볼 수도 있지만, 그보다 **두 문서가 서로 모순되는 상태 자체가 법적으로 위험합니다.**

추가로 1조 수집항목이 *"이용자가 입력한 연락 수단"* 으로 한정돼 있는데, 카카오싱크는 입력이 아니라 **카카오로부터 제공받는** 것이라 수집 경로를 명시해야 합니다.

**→ 정훈이가 (2)를 먼저 고치고, (1)은 반려되면 그때 대응하는 걸로 갑니다.** 형은 ①②부터 진행해 주세요.

## 7. 끝나면

**정훈이한테 이 두 개만 알려주세요.**

1. 비즈니스 인증 완료 여부
2. 전화번호 동의항목 **승인/반려** 결과 (반려면 사유 그대로)

승인이면 앱 쪽에서 `NEXT_PUBLIC_KAKAO_PHONE_SCOPE=on` 켜고 배포하면 끝입니다. 반려면 사유 보고 신청서 고쳐서 재신청하고, 그동안은 지금 흐름 그대로 돌아갑니다.
