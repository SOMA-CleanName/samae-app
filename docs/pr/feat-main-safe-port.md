브랜치 `feat/main-safe-port` → `main` · 커밋 4개 · 46파일 (+5,027 / −22)

---

## 왜 이 PR 이 있나

`dev` 가 `main` 보다 **149 커밋** 앞서 있습니다. 그런데 그 대부분이 리드 모델을 폐지하고 채팅 상주·에스크로로 갈아엎는 작업이라 **PG 계약 전에는 배포할 수 없습니다.** 배포하는 순간 작가가 연락처를 사는 현재의 수익 경로가 통째로 사라집니다.

문제는 그 안에 **결제·문의와 아무 상관 없는 지면 자산**이 같이 묶여 있다는 것이었습니다. 아티클·촬영 가이드 33편·촬영 장소 18곳은 순수 획득 자산이고, SEO 는 색인에 시간이 걸리므로 PG 를 기다릴 이유가 없습니다. **4주를 통째로 버리게 됩니다.**

이 PR 은 그중 안전한 것만 골라 옮깁니다.

---

## 어떻게 갈랐나

커밋 단위로는 **못 뽑습니다.** 실제로 시험해 봤고 두 번째 커밋에서 바로 막힙니다.

```
✅ docs: 문의·채팅 시스템 인수인계 문서
❌ feat: 홈 배너 — 어드민 관리 이미지 캐러셀
      충돌: src/app/(user)/page.tsx
```

홈 하나에 배너·매거진·피드·문의 CTA·챗봇 진입이 **한 파일에** 들어 있습니다. 사진 상세도 같은 구조고요.

그래서 커밋이 아니라 **파일 성격**으로 갈랐습니다.

```
199 파일  dev 에서 새로 생김  → main 에 없으므로 충돌 자체가 불가능
 93 파일  기존 파일 수정      → 이쪽이 얽힘의 근원
```

새 파일만 가져오고, 전이 의존을 닫아서 38개로 확정했습니다. 기존 파일 수정은 **5개**만 손댔습니다 — `seo.ts`(dev 판이 상위집합) · `sitemap.ts` · `robots.ts` · 홈 · `/terms`.

### 2. 탐색 카테고리 빈 페이지 — **프로덕션 실버그**

> 배정 사진이 300장 넘는 무드 카테고리 10개가 0장으로 렌더되고 있었다.
> PostgREST 는 `.in(...)` 을 쿼리스트링으로 내보내는데 id 가 수백 개면 URL 길이 한계를
> 넘고, 이때 **에러 없이 data 가 null 로 돌아온다.** 그래서 실패가 빈 배열처럼 보였다.

`our-vibe` · `vintage-memories` · `natural-look` 등이 **지금 빈 페이지입니다.** 100개씩 끊어 조회하도록 고칩니다.

### 3. SEO

사이트맵에 아티클·가이드·장소 전부 등재. AI 크롤러(GPTBot·PerplexityBot·ClaudeBot·Google-Extended)를 `*` 로 이미 허용되는데도 **명시**합니다 — 나중에 `*` 를 조이는 순간 AI 노출이 조용히 사라지는 사고를 막기 위해서입니다. 비프로덕션은 전체 차단(프리뷰 중복 색인 방지).

### 4. 사업자 정보 — **PG 심사 요건**

전자상거래법 제10조 + KG이니시스 안내(*"사이트 하단 사업자정보 확인 가능한 단계까지 구축"*).

주소            인천광역시 연수구 인천타워대로 323, A동 31층 3101호

푸터는 끝이 있는 지면에만 닿으므로 **홈은 무한 피드 직전**에 따로 뒀습니다. 심사관이 유입 1위 지면에서 못 찾으면 거기서 걸립니다.
