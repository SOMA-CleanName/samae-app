# 안내 이미지 — 크기 통일 · 빈칸 제거 · 아래로 끌어 닫기

#394 에 이어지는 다듬기. 발행 자체는 이미 돌고 있고(모글필름 7장 라이브), 여기서는 **보이는 모양**만 고친다.

## 왜

한 작가의 안내 이미지가 레일에 나란히 걸리는데 높이가 1,805~2,408px 로 제각각이라 목록으로 안 읽혔다. 그리고 본문과 푸터 사이에 최대 768px 이 비어 있었다.

## 변경점

### 1. 쓸데없는 아래 여백 제거 (`b824665`)

높이는 글자 수로 어림할 수밖에 없다 — Satori 는 레이아웃을 돌려주지 않는다. 어림은 안전하게 잡아야 해서 늘 넉넉하고, 카드가 많은 장에서는 그 오차가 쌓인다.

한 번 굽고 재서 다시 굽는다(`renderGuideCardFitted`). 글자가 없는 가로줄이 가장 길게 이어지는 구간을 찾아 그만큼 줄인다 — 카드 사이 간격이 100px 이라, 그보다 훨씬 긴 구간 하나가 곧 그 빈칸이다.

```
라벨형 3080→2408 · 봉투형 3244→2556 · 장부형 3028→2467   (5장 평균 -470px)
```

표지형은 건드리지 않는다. 큰 제목 하나에 여백을 크게 두는 게 그 양식의 의도다.

### 2. 세트 전체를 같은 크기로 (`cc1f166`)

`renderGuideSet` 이 세트를 가장 긴 장에 맞춰 굽는다. 크기를 맞추면 짧은 장에 빈칸이 생기므로, **맞추기 전에 분량부터 고르게 나눈다.**

- 장 나누기 기준을 카드 수 → **줄 수**로 바꿨다. 긴 카드 셋이 짧은 카드 여섯보다 길어서 카드 수로 세면 소용이 없다
- 쪼갤 때 앞을 꽉 채우지 않고 반반으로 나눈다. 옛 규칙은 `8장+1장` 이 나와 뒷장이 통째로 빈칸이 됐다

```
전 · 5장 · 높이 1,805~2,408 · 최악 빈칸 603px
후 · 7장 · 전부 1,960      · 최악 빈칸 548px
```

**쪼갤수록 좋은 게 아니다.** 상한을 24줄로 잡았더니 전부 갈라져 10장이 됐는데, 장이 늘면 제목·푸터가 또 붙어 빈칸 총량이 1,645 → 4,335px 로 **늘었다.** 유난히 긴 장만 덜어내는 30줄에서 멈춘다.

미리보기도 같은 공통 높이를 쓴다. 높이는 세트 전체를 재야 나오는데 요청은 한 장씩 들어오므로, 양식이 같은 동안은 캐시한다 — 안 그러면 조합 하나에 25번 굽는다.

### 3. 레일 카드 크기 통일 (`b824665`)

3:4 틀에 **위 기준**으로 맞춘다. 맨 위 제목(`Price / 가격·구성`)이 곧 그 장의 이름이라 잘려도 무엇인지 보인다. 아래에 옅은 그라데이션으로 "더 있다" 를 알린다. 카드 폭 68% → 132px.

뷰어에서는 화면 높이에 맞추지 않고 **폭을 채우고 세로로 스크롤**한다. 세로로 긴 안내물을 높이에 맞추면 글자가 읽을 수 없게 작아진다.

### 4. 아래로 끌어 닫기 (`f368b3b`)

끌리는 만큼 그림이 따라 내려가고 배경이 옅어진다.

- **맨 위에 닿아 있을 때만** 닫기로 친다. 슬라이드마다 세로 스크롤이 있어서, 아무 데서나 받으면 읽으려고 스크롤 올리는 동작마다 닫힌다
- 처음 8px 로 가로/세로 중 어느 제스처인지 정하고 바꾸지 않는다. 애매하면(세로가 가로의 1.2배 미만) 장 넘기기 쪽을 살린다

## 같이 잡은 버그

**카드 0장짜리 안내 이미지가 발행됐다.** 상한 계산상 두 묶음이 필요한데 카드가 그만큼 없으면 빈 묶음이 그대로 한 장이 된다 — 실측에서 `컨셉 (2/2)` 가 그렇게 나왔다. 빈 묶음을 걸러내고 번호를 다시 매긴다. 테스트로 박았다.

## 확인

```bash
npx tsx --test src/lib/*.test.ts                 # 567 통과 (신규 3)
npm run build                                     # 통과
npx tsx scripts/guide-fit-check.tsx <카드JSON>     # 5글씨체×6템플릿×7장 안 잘림
```

발행 결과(모글필름, 라이브): 7장 전부 `1080×1960`, 공개 URL 200.

## 남은 것

지금 1,960px 바닥을 만드는 건 `컨셉` 장이다. 세계관 예시를 나열한 카드 하나가 173자라 더 못 쪼갠다. 그 카드를 둘로 나누거나 줄이면 세트 전체가 1,500대로 내려간다 — 내용 판단이라 손대지 않았다.
