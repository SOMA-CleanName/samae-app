# 작가에게 덜 묻고, 작가가 직접 고치게

실제 작가 두 명(모글필름·주미)을 세팅하면서 나온 것들. 프롬프트 품질 3건 + 버그 2건 + 스튜디오 기능 1건.

## 1. 안 물어도 되는 걸 묻고 있었다

주미 작가 건에서 질문 8개가 나왔는데 **절반이 물을 필요 없는 것**이었다. 작가가 보낸 자료는 대개 **요약**이고 사매 패키지는 그 **상세**인데, 둘이 달라 보이면 무조건 불일치로 올렸다. 실제로는 같은 말을 다른 크기로 쓴 것이다.

거르는 규칙을 프롬프트에 넣었다.

| 불일치가 아닌 것 | 예 |
|---|---|
| 요약 ↔ 상세 | "세부보정 할인" vs "리퀴파이 할인"·"보정본 2장 추가" |
| 기본값 ↔ 상품별 값 | "기본 보정본 6장" vs 상품마다 6·8·10장 |
| 최저가 ↔ 더 싼 다른 상품 | "개인스냅 50,000원부터" 옆의 20,000원 체험 상품 |
| 상한 ↔ 작가 기준 | 납품 21일 한도 안에서 작가가 10일 |
| 명백한 오타 | "4~60분" 은 40~60분 |

**묻기 전에 그 상품 설명을 끝까지 읽게 했다.** 금액 차이의 이유는 대개 거기 적혀 있다 — 입문 패키지는 "스냅 초보분들께 추천", 페이스 프로필은 "흉상~두상만 촬영". 자료를 읽었으면 물을 일이 아니었다.

**겹치는 항목은 묶어서 제안하게 했다.** 항목마다 "이게 맞나요" 를 늘어놓으면 안내물 하나 만드는 데 취조받는 느낌이 된다. `"등록해두신 패키지 기준으로 정리해드려도 될까요"` 한 문장을 questions 맨 앞에 두고, 뒤에는 **자료에도 패키지에도 없어서 정말 모르는 것**만 남긴다.

두 줄 더:
- **작가의 선택을 캐묻지 않는다** — 동의하지 않은 항목, 켜지 않은 설정은 그렇게 정한 것이다
- **해줄 수 없는 것을 약속하지 않는다** — "알아보겠다" 류 금지

같은 자료로 다시 돌린 결과: **불일치 5 → 0, 질문 8 → 5.**
남은 질문은 전부 진짜다. 그중 하나는 손으로 거를 때 놓쳤던 것 — 대부분 패키지는 "리퀴파이 할인" 인데 커플/우정 실내만 "리퀴파이 무료" 로, 작가 자신의 설명끼리 어긋나 있었다. 작가가 확인하고 고쳤다.

## 2. 출장비 0 을 "무료" 로 읽고 있었다

`0 = 출장 옵션 없음`(0011 주석)인데 프롬프트에 `출장비: 0원` 으로 넘기고 있었다. 모델이 **"출장비는 따로 받지 않아요"** 카드를 만들었다 — 작가가 한 적 없는 약속이고, 야외 촬영이 많은 작가라면 받아야 할 돈을 못 받는다.

실측 기준 **21명 전원이 0** 이다(아무도 설정하지 않았다는 뜻). 모든 작가에게 똑같이 터질 버그였다.

## 3. KB 첫 저장이 조용히 사라졌다

발행 스크립트가 `update` 를 써서, KB 행이 아직 없는 작가(처음 등록)는 카드가 저장되지 않았다. 그런데 이미지는 메모리의 카드로 구워지니 `KB 저장 · 카드 24장 / 발행 완료` 가 그대로 찍혔다 — **실패가 성공처럼 보였다.** 확인 쿼리를 돌리지 않았으면 챗봇이 빈 KB 로 답하고 있었을 것이다.

`upsert` + 쓴 값 되받아 확인으로 바꿨다.

## 4. 스튜디오 — 썸네일과 양식 고르기

**썸네일이 80×96 에 `object-cover`** 였다. 안내 이미지는 세로로 길고 글자가 들어 있어서 그 크기로 자르면 무슨 장인지도 안 보였다. 3:4 틀에 위를 기준으로 맞춰 맨 위 제목이 읽히게 하고, 누르면 원본을 크게 연다.

**양식을 작가가 못 골랐다.** 운영 화면에만 있어서 작가는 템플릿·배경지·글씨체를 바꾸려면 운영팀에 말해야 했다. 스튜디오에 같은 고르기 화면을 붙였다.

작가가 바꾸는 것은 **겉모습뿐이다** — 내용(KB 카드)은 운영이 등록하고 작가는 못 바꾼다. 틀린 정보가 나갈 길이 없어서 검토 없이 바로 다시 굽는다.

복제하지 않으려고 셋을 공용으로 뺐다. 한쪽만 고치면 운영 화면과 작가 화면의 양식이 갈린다.

- `components/guide/GuideStylePicker` — 고르기 화면. 주소·저장 방법만 주입받는다
- `lib/guide-bake` — 굽고 올리는 알맹이. 어드민 [이미지 발행] 도 이걸 부른다
- `lib/guide-card-route` — PNG 라우트의 알맹이. 라우트는 인증과 대상 작가만 맡는다

작가용 라우트·액션은 **`pid` 를 받지 않는다.** 세션의 작가 행에서 꺼낸다 — 쿼리로 받으면 남의 id 를 끼워 넣어 다른 작가 KB 를 그려 볼 수 있다.

## 남은 것

작가가 패키지를 고쳐도 안내 이미지·챗봇은 그대로다. 첫 단계는 **패키지 `updated_at` > KB `updated_at` 이면 어드민에 "갱신 필요" 배지**. 완전 자동은 추출에 쓴 작가 원본 자료를 저장해야 가능하다(지금은 저장하지 않는다).
