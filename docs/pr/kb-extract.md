# 작가 자료 → KB 카드 → 사매 안내 이미지

작가마다 제각각인 촬영 안내물을 사매 양식으로 통일하고, 같은 데이터를 챗봇이 쓰게 한다.

## 왜

작가들은 가격·진행방식을 각자 만든 이미지로 올린다. 문제는 **그 이미지와 챗봇 답변이 따로 논다**는 것이다. 가격이 바뀌면 이미지를 다시 만들고 챗봇 KB도 따로 고쳐야 하는데, 실제로는 한쪽만 고쳐지고 나머지가 남는다. 가격·환불 문구가 어긋나면 분쟁 때 근거가 된다.

그래서 입력을 이미지가 아니라 **KB 카드 한 벌**로 잡았다. 카드를 고치면 그림과 챗봇이 같이 바뀐다 — 어긋날 구조 자체가 없다.

## 흐름

```
작가 자료(노션·이미지·글)
  → [추출]  모델이 읽어 카드 + 충돌 + 질문지
  → [대조]  자료 · 패키지 · 소개글 3자 비교 → 다른 점만 작가에게 질문
  → [저장]  photographer_bot_kb  ← 챗봇이 이미 읽는 곳
  → [이미지] 같은 카드로 안내 이미지 렌더
```

## 변경점

### 1단계 — KB 추출 (`ead9411`)

- `src/lib/kb-extract.ts` — 자료를 카드·충돌·질문지로. 공식 Anthropic SDK `output_config.format` + 스트리밍
- 3자 대조(자료·패키지·소개글). 사매 데이터끼리도 안 맞는 경우가 있어 2자 비교로는 부족했다
- 질문지는 **모르는 것만** — 자료에 있는 걸 되묻지 않는다
- 금지어(외부 채널·환불·계좌·전화번호)를 코드로 한 번 더 거른다. 버리지 않고 `held` 로 빼 사람이 판단
- 핵심 토픽 누락은 코드가 센다(모델에게 맡기면 빠뜨린다)
- `src/lib/anthropic-client.ts` — 봇·추출이 같이 쓰는 워크스페이스 헤더 설정 분리

### 2단계 — 안내 이미지 양식 (`4815bce`)

- 템플릿 6종 · 배경지 8종 · 글씨체 5종, 작가별 저장 (`photographers.guide_style`)
- 고르는 즉시 미리보기 재렌더, 클릭하면 확대
- 배경 사진 업로드 가능 — 그 위에 반투명 종이를 덮어 **어떤 사진이든 글이 읽히게**
- `/api/admin/guide-card` — 운영자 전용 PNG 라우트 (KB 를 service_role 로 읽으므로 공개 불가)

## 확인

```bash
npx tsx --test src/lib/*.test.ts        # 555 통과
npm run build                            # 통과
npm run lint                             # 새 파일 에러 0 (기존 22건은 main 에 이미 있던 것)
npx tsx scripts/guide-fit-check.tsx <카드JSON>   # 150조합 안 잘림
```

읽힘은 취향이 아니라 조건이라 테스트로 고정했다:

- 배경지의 **가장 어두운 픽셀** vs **가장 옅은 글자** ≥ 4.5:1 (WCAG 본문)
  본문만 재다가 헤더·푸터가 통째로 묻힌 적이 있어 세 단계를 다 잰다
- 글씨체 5 × 템플릿 6 × 장 5 = 150조합에서 마지막 줄이 안 잘리는지

### 같이 고친 것 — 줄 수 어림

폭 ÷ 글자크기 로만 세면 **늘 모자라게 나온다.** 한국어는 어절 단위로 끊겨서(`keep-all`) 줄 끝에 다음 어절이 안 들어가면 그대로 비우고 내려간다. 실제로 채워지는 건 폭의 9할쯤이라, 그 낭비를 안 빼면 줄 수를 적게 잡고 마지막 줄이 잘린다. 기본 글씨체에서도 이미 1px 차로 아슬아슬했다.

`WRAP_FILL 0.9` + 템플릿별 실제 본문 폭(766/852/844/830)으로 고쳤다. 가장 빠듯한 조합 여유 38px.
