# 전수 재검증 — 이 세션에서 한 모든 주장의 근거

검증일 2026-09-04 · 요청: *"지금까지 모든 결정과 기록을 전부 근거 기반으로 재검토"*

---

## 왜 이 문서가 있나

한 세션에서 **여덟 번 말이 바뀌었다.** 원인은 하나다 — **확인할 수 있는 것을 확인하지 않고
먼저 말했다.** 회원 수는 쿼리 한 번, 구매안전서비스 발급처는 검색 한 번, 홈·탐색의 채팅
결합 여부는 grep 한 번이면 나왔다. 추론으로 답하고 지적받으면 그때 찾아보는 순서였다.

그래서 **이 세션에서 만든 모든 문서의 사실 주장을 기계적으로 다시 검증했다.**
아래는 그 결과다. **확인 못 한 것은 확인 못 했다고 적었다.**

## C. 🔴 가장 중요한 정정 — "공정위 3요소" 가 아니라 **법 제20조**

이 세션 내내 *"공정위 통신판매중개자 판단 3요소 — (ⅰ)고지 (ⅱ)결제화면 표시 (ⅲ)회계처리"*
를 근거로 삼았다. 그런데 **그 표현의 출처를 확인하지 못했다.** 이전 세션 기록에서
이어받아 그대로 썼고, 나는 검증 없이 반복했다.

**대신 더 강한 근거를 찾았다 — 전자상거래법 제20조는 이것을 법정 의무로 규정한다.**

> 통신판매중개자는 자신이 통신판매의 **당사자가 아니라는 사실**을 소비자가 쉽게 알 수 있도록
> **미리 고지**해야 하고, 청약이 이루어지기 전에 **중개의뢰자의 신원정보**(성명·상호·
> 대표자명·주소·전화번호 등)를 소비자에게 **제공**해야 한다.

### 무엇이 달라지나

| | 3요소로 말했을 때 | 제20조로 말하면 |
|---|---|---|
| 성격 | "갖추면 중개자로 인정받기 유리" | **"안 하면 법 위반"** |
| 지금 상태 | (ⅰ)(ⅱ) 미구현 → 불리 | **법정 의무 미이행** |
| 조치의 무게 | 선택 | **필수** |

**결론은 같지만 이유가 다르고, 이유가 훨씬 강하다.** 결제 화면의 「판매자: ○○ 작가」와
중개자 고지는 "유리해지는 장치" 가 아니라 **법이 요구하는 것**이다.

⚠️ 다만 사매가 **중개자로 판정될 때**의 의무다. 통신판매업자로 보면 제20조가 아니라
   더 무거운 책임이 온다. 어느 쪽이든 **지금 아무것도 안 하고 있는 것이 가장 나쁘다.**

## D. 재검증에서 **새로 발견한 구멍**

### 🔴 `/terms` 링크가 초기화면에 없었다

제10조 요구 항목에 **"사이버몰 이용약관"** 이 있다. 그런데 푸터·홈 링크줄 어디에도
`/terms` 링크가 없었다 — 가입 화면에서만 연결됐다.

**법정 표시 항목 하나가 빠져 있었고, 약관을 만들면서도 못 봤다.**
→ `SiteLinksRow`·`SiteFooter` 에 추가하고, `business-info.ts` 주석에 제10조 요구 항목
   전문을 박아 뒀다(다음에 누가 링크를 정리하다 빼지 않도록).

### 🟡 전화번호·모사전송번호

제10조는 **전화번호**를 요구한다. 지금 비어 있다(유심 대기). **모사전송번호(팩스)** 도
문언에 있는데 팩스가 없는 사업자의 처리는 확인하지 못했다.

## E. 판단·권고의 상태

사실이 아니라 **판단**인 것들이다. 근거가 있어도 다를 수 있다.

| 판단 | 근거 | 상태 |
|---|---|---|
| dev 를 지금 배포하면 안 된다 | 리드 수익 경로 소멸 | ✅ 정훈 지적으로 수정됨 |
| 홈·탐색은 채팅과 결합 안 됨 | grep 으로 확인 | ✅ 검증됨 |
| 연락처 전달 50% 유지 + 세이빙 클로즈 | 팀 결정 + 제17조②5호 단서 | ✅ 결정 기록됨 |
| 30일 공지 불필요 | 순수 고객 회원 2명 | ✅ 쿼리로 확인 |
| 임박 예약은 "리스크가 작다"(안전이 아님) | 제17조②6호 3요건 | ✅ 표현 수정됨 |
| PG 심사에 main 법무 정비가 필요 | KG 안내(사용자 제공) | ⚠️ **KG 원문 재확인 못 함** |
| KG 지급대행 건당 500원 | 이전 세션 KG 회신 | ⚠️ **재확인 못 함** |

## F. 앞으로의 규칙

1. **법령·제도·수치는 확인하고 말한다.** 확인 못 했으면 답하기 전에 그렇게 밝힌다
2. **이전 세션에서 이어받은 주장도 검증 대상이다.** "3요소" 가 그렇게 통과했다
